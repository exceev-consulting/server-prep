Brand guidelines

One keyhole, one colour, black or white.

How to use the server-prep logo, colours, type and voice. Everything here comes from the repository: the logo files in .github/assets and the design tokens in site/tokens.css, which the setup console uses too.

01

Logo

A rounded tile with a keyhole cut through it: a server, locked down. It is one shape in one colour, so it holds up at 16 px and in any medium.

1.1

The mark

Use it in black on light backgrounds and in white on dark ones. The keyhole is a hole, so whatever is behind the tile shows through it.

1.2

Construction

Drawn on a 64-unit grid. Use the SVG files as they are: never redraw the mark or trace it from a screenshot.

A
Tile. 64 × 64 units, corner radius 18. Solid, one colour.
B
Keyhole head. A circle 18 across, centred at 32, 27.
C
Keyhole stem. 8.4 wide at the neck, 12.6 at the base, base corners rounded 2.6.
↕
Balance. The keyhole is 28 tall with 18 clear above and below, centred on the vertical axis.
∅
One path. Tile and keyhole are a single path with fill-rule="evenodd". The keyhole never gets a colour of its own.
1.3

Clear space and size

Keep a quarter of the tile clear on every side: 16 units when the tile is 64. The mark works down to 16 px. Below 20 px tall, use the mark without the name.

Clear space

Sizes

1.4

Mark and name

The name sits to the right of the mark, a quarter of the tile away, in IBM Plex Mono SemiBold. Always lowercase, always with the hyphen.

In an interface

server-prep

Top bars use a 28 px mark, the name at 16 px and a 10 px gap, as in the setup console.

1.5

Versions

Four files cover every case. Pick by the background, not by taste.

1.6

Misuse

The mark has one shape and one colour. Anything that adds to it makes it someone else's logo.

03

Typography

Three faces, one job each: Barlow Condensed for headlines and labels, IBM Plex Sans for reading, IBM Plex Mono for anything you type. All three are free on Google Fonts.

3.1

Typefaces

Keep the roles apart. A condensed face in a paragraph is hard to read, and a command set in the text face is easy to mistype.

3.3

Emphasis

To stress words in a headline, brighten them and underline them in the same colour: 0.07em thick, 0.14em below. No highlighter blocks, no second hue.

Interface

The parts the setup console is built from. Reuse them before you design new ones.

Buttons and links

One primary button per view. On the rack band the primary button turns white.

4.2

Pills, chips and labels

Pills state a result. Chips name a value you could type. Eyebrows introduce a block, with the short dash in the accent colour.

05

Voice

Write for someone who has never hardened a server. Simple words, short sentences, and proof instead of promises.

5.1

Principles

The same rules apply to the README, the wiki, script output and issues.

Say what happens

Name the change and its effect, in the active voice. "Disables password login", not "password login will be disabled".

Keep it short

One idea per sentence. Plain words over jargon; explain a term the first time it appears.

Show the proof

Point to the audit, the test run or the exact command. Never claim "secure" without saying what was checked.

5.2

Write this, not that

Examples from the kind of text the project writes every day.

WriteNotWhy
Disables password login. Use an SSH key instead.Password-based authentication mechanisms will be deactivated.Active voice, plain words, the next step.
2 checks failed. Run these commands to fix them.Oops! Something went wrong with your server!!An error names the problem and the fix.
Tested on Ubuntu 22.04, 24.04 and 26.04, and Debian 12 and 13.Military-grade, bulletproof security.Facts you can check beat adjectives.
server-prep sets up the firewall.Server Prep / ServerPrep / SP sets up the firewall.The name never changes form.
5.3

Names and examples

Public text is read by strangers. Examples must work for anyone and expose no one.

The project
server-prep: lowercase, with the hyphen, even at the start of a sentence. Scripts in mono: server-prep.sh, server-audit.sh, server-preconfig.sh.
Results
PASS, WARN, FAIL and INFO in capitals, as the audit prints them.
Panels
By their own names: Coolify, Dokploy, Openship.
Examples
Host web-01, domain example.com, addresses from 203.0.113.0/24. Never a real client name, domain, address, token or key, in text or in screenshots.
