From a fresh server to a panel-ready one, with proof.

server-prep locks down a new server (SSH keys on a new port, a firewall that also covers Docker, intrusion blocking, automatic security updates) and gets it ready for your deployment panel. An audit runs before and after, so you see what changed.

Typical result on a prepared host: about 43 PASS. Normal WARNs: pending regular updates, a reboot after a kernel upgrade.

Score = (PASS × 100 + WARN × 50) ÷ scored checks. INFO never counts. server-audit.sh exits with 1 when any check FAILs.

    If SSH locks you out: log in from the console. sudo ufw disable opens the firewall again. sudo bash /var/lib/server-prep/backups/<date>/rollback.sh restores every file server-prep changed. The 10-minute auto-undo only covers the SSH settings, not the firewall.
