# Guides (docs/)

The root `AGENTS.md` has the project rules and the Definition of done. These rules are for the guides:

- Link the official docs at each step, where the command or setting is used.
- End every guide with a `## Troubleshooting` section (symptom, cause, fix), then a `## Official docs` section that lists the links used.
- One copy-paste block per step, and say what output to expect.
- Use placeholders such as `<influxdb-token>` for secrets, never a real token, key or password.
- Simple words and short sentences: many readers are not security experts.
